# Roadmap

What Atlas is working on next to make it easier for teams outside BlitzCraft to adopt Atlas and stay
current. Items link to their tracking issue. This page is updated when an item ships or changes
priority; the [changelog](../../CHANGELOG.md) is the record of what has shipped.

## Now — staying current

| Item                                                                 | Issue                                                      |
| -------------------------------------------------------------------- | ---------------------------------------------------------- |
| Upgrade across several published releases in one command             | [#110](https://github.com/blitzcraftlabs/atlas/issues/110) |
| Weekly upgrade pull requests for consumers (`atlas enable upgrades`) | [#109](https://github.com/blitzcraftlabs/atlas/issues/109) |
| Three-way merge for synced files you customized                      | [#111](https://github.com/blitzcraftlabs/atlas/issues/111) |
| Baseline keeps customizations detectable across upgrades             | [#125](https://github.com/blitzcraftlabs/atlas/issues/125) |
| GitHub Releases public only after npm publication                    | [#112](https://github.com/blitzcraftlabs/atlas/issues/112) |
